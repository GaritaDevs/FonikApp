
# User Stories

The following user stories describe the features and functionality of the German Learning Tracker. They are divided into **Minimum Viable Product (MVP)** features and future improvements.

## Minimum Viable Product (MVP)

The MVP includes the core features necessary for users to save German vocabulary, review grammar, and practice using flashcards.

### 1. User Registration and Login
- **US-01:** As a user, I want to create an account so that I can securely access my personal vocabulary and learning progress.
- **US-02:** As a registered user, I want to log in and log out so that I can access my account securely.

### 2. Vocabulary Management
- **US-03:** As a user, I want to add German words with their English meanings so that I can build my own vocabulary list.
- **US-04:** As a user, I want to save the grammatical gender (der, die, or das) of nouns so that I can practice using the correct article.
- **US-05:** As a user, I want to record the plural form of nouns so that I can learn how words change from singular to plural.
- **US-06:** As a user, I want to edit and delete saved vocabulary so that I can keep my word list accurate and organized.
- **US-07:** As a user, I want to view my saved vocabulary so that I can review the words I have learned.

### 3. Grammar and Cases
- **US-08:** As a user, I want to view the four German grammatical cases (nominative, accusative, dative, and genitive) so that I can understand how they are used.
- **US-09:** As a user, I want to save case-specific articles and word forms so that I can practice how German words change depending on the case.

### 4. Flashcards
- **US-10:** As a user, I want to practice my saved vocabulary using flashcards so that I can improve my memory and recall.
- **US-11:** As a user, I want to reveal the English meaning or German word on a flashcard so that I can test my knowledge before seeing the answer.
- **US-12:** As a user, I want to mark whether I answered a flashcard correctly or incorrectly so that I can identify vocabulary that needs more practice.

### 5. External API Integration
- **US-15:** As a user, I want to search for German words using a dictionary API so that I can find word meanings and grammatical information without entering everything manually.
- **US-16:** As a user, I want to retrieve German noun articles and plural forms from an external service when available so that I can save vocabulary more efficiently.
---

## Future Improvements

These features are outside the initial MVP but could be added in future iterations.

### 6. Learning Progress
- **US-13:** As a user, I want to track my flashcard performance so that I can monitor my learning progress over time.
- **US-14:** As a user, I want to review words I frequently get wrong so that I can focus on areas where I need improvement.


### 7. Additional Features
- **US-17:** As a user, I want to filter my vocabulary by grammatical gender or case so that I can focus on specific grammar topics.
- **US-18:** As a user, I want to practice vocabulary by difficulty level so that I can gradually improve my German skills.
